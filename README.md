# Learning to Walk Like Humans Do with Reinforcement Learning

This repository contains the core code and summarized results from my junior thesis project at Princeton (Spring 2025). 


The project explores **humanoid locomotion** through reinforcement learning, inspired by **human development** and the principle of "starting small." We explore two dimensions: **expanding networks** that increase in model size (width and depth) over time and a **curriculum** of subtasks inspired by human motor development. 

In results/, you can find our key findings, including the expanding network ablations (width and depth) and curriculum skill baselines. 

This project is continued and heavily refined in my senior thesis work, listed as a repository on my page.
